# LaTeX Documentation

## 1. Introduction

LaTeX is a document preparation system used to create professional documents. It is widely used for academic reports, research papers, assignments and technical documents.

## 2. Basic LaTeX Structure

A basic LaTeX document contains:

- `\documentclass{article}` – Defines the document type.
- `\begin{document}` – Starts the document content.
- `\end{document}` – Ends the document.

## 3. Basic Example

```latex
\documentclass{article}

\title{My First LaTeX Document}
\author{Your Name}
\date{\today}

\begin{document}

\maketitle

\section{Introduction}
This is my first LaTeX document.

\end{document}
```
